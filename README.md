# Akumulatory Tarnów

Strona Pogotowia Akumulatorowego: pełna oferta 338 produktów, kategorie i filtry,
usługi, porady, anonimowe opinie Google i kontakt. Bez transakcji internetowych.

GitHub Pages: https://kosma0000.github.io/akumulatory-tarnow/

## Podgląd lokalny

```sh
python -m http.server 8767 --bind 127.0.0.1 --directory public
```

Otwórz http://127.0.0.1:8767/akumulatory-tarnow/.

## Publikacja

Pliki strony są w `public/akumulatory-tarnow/`. GitHub Actions publikuje zmiany
wysłane na `main`. Strona nie wymaga instalacji zależności ani kompilacji.
